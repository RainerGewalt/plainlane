# Contributing

Plainlane welcomes focused fixes and small improvements that respect the boundaries in [AGENTS.md](AGENTS.md).

1. Open an issue for changes that affect behaviour or persistence.
2. Keep pull requests narrow and use neutral example data.
3. Run `npm run build`, `node --check server/index.js`, and `docker compose config`.
4. Never include `.env`, databases, exports, attachments, or personal information.

Bug reports should include the browser, Docker version, steps to reproduce, and relevant logs with secrets removed.
